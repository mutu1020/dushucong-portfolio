# 341 画风库 · 在线版

把中文文案做成代码动画（Remotion / Canvas / HTML）时用的**画风提示词库**，共 **341 种风格**，其中 193 种带静帧。这是一个纯静态的浏览站：按分类筛、全文搜索、看原文、复制提示词、收集清单，都能在浏览器里完成，不需要后端。

## 这里有什么

| 路径 | 内容 |
|---|---|
| `index.html` | 浏览站本体（单文件，全部 341 条原文内嵌，1.6MB） |
| `styles.json` | 341 条的元数据（编号、名称、分类、长什么样、适合、关键词、缩略图路径、SHA），方便别的工具直接读 |
| `代码动画/风格提示词/` | 341 个 `.md` 原文，带静帧的旁边有同名 `.jpg` |
| `代码动画/示例/` | 两组实测对照：同一份提示词给 Opus 5.5 与 DeepSeek 的成片；只给一句话给 DeepSeek 的结果 |
| `代码动画/第三方许可/` | Lemo-Opuscar、code-video、mg-styles-15 三个上游项目的原始许可 |

## 用法

打开站点 → 搜编号或关键词 → 点卡片看完整原文 → 「复制原文」直接粘给模型。

收集用的话点卡片右上角 ★，底部「清单」里导出，得到的文本可以直接喂给命令行工具做批量取文：

```
L36 蓝图 · 工程制图
Z5 剪纸
```

## 本地维护

站点由 `build_site.py` 生成（仅用 Python 标准库）：

```sh
python3 build_site.py --out . --asset-base ./代码动画/
```

改库后重跑一次即可重建 `index.html` 与 `styles.json`。
